# Cinema Commerce Platform

Projeto de estudo dividido em aplicações independentes:

- `web`: painel administrativo em React e TypeScript;
- `mobile`: aplicativo em React Native, Expo e TypeScript;
- `backend`: será criado posteriormente com ASP.NET Core.

## Executar o painel web

```powershell
cd web
npm run dev
```

## Executar o aplicativo móvel

```powershell
cd mobile
npm start
```

Use o aplicativo Expo Go para ler o QR Code ou pressione `w` para abrir a versão web.

## Roteiro de aprendizado

1. Componentes, JSX e variáveis.
2. Estado com `useState`.
3. Eventos de clique e toque.
4. Formulários e validação.
5. Consumo da API ASP.NET Core.
6. Pedidos, pagamentos e estoque.
